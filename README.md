# FitTrack

אתר מקומי למתאמנים מתחילים: פרופיל, הערכת תזונה, הצעת ארוחות, תוכנית אימונים ומעקב התקדמות.

האתר רץ על המחשב שלך. אין צורך באינטרנט אחרי ההתקנה, ואין מפתח API.  
הנתונים נשמרים בקובץ `data/fittrack.db`.

המידע באתר הוא הערכה כללית למבוגרים בריאים מגיל 18 עד 80. הוא לא ייעוץ רפואי, תזונתי או אימון אישי.

## התקנה

פותחים PowerShell בתיקיית הפרויקט ומריצים:

```powershell
cd C:\Users\User\OneDrive\Desktop\FitTrack
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

אם ההפעלה של הסביבה נחסמת, אפשר לדלג על `Activate` ולהשתמש בפקודה המלאה שמופיעה למטה.

## הפעלה

אחרי שהסביבה פעילה:

```powershell
streamlit run app.py
```

בלי הפעלה של הסביבה:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

הדפדפן נפתח לכתובת `http://localhost:8501`.  
כדי לעצור את האתר, חוזרים לחלון PowerShell ולוחצים `Ctrl+C`.

## מה יש באתר

1. **פרופיל** — גיל, מין לצורך נוסחת האנרגיה, גובה, משקל, פעילות, ניסיון, מטרה וימי אימון.
2. **תזונה** — הערכת קלוריות לפי Mifflin–St Jeor, יעדי חלבון, פחמימות ושומן, ואפשרות לשנות אותם. מתחת מופיעה הצעת ארוחות עם כמויות משוערות.
3. **אימונים** — תוכנית לפי המטרה, הניסיון ומספר הימים. לכל תרגיל יש סטים, חזרות והסבר קצר.
4. **התקדמות** — יומן משקל, תוצאות אימון וסיכום תזונה יומי, עם גרפים.

## מבנה הקבצים

| קובץ | תפקיד |
| --- | --- |
| `app.py` | מפעיל את האתר, העיצוב והתפריט |
| `fittrack/pages.py` | ארבעת המסכים |
| `fittrack/database.py` | שמירה וטעינה ב-SQLite |
| `fittrack/nutrition.py` | נוסחת הקלוריות ומאגר הארוחות |
| `fittrack/workouts.py` | בניית תוכנית האימון |
| `fittrack/validation.py` | בדיקת המספרים שהמשתמש מזין |
| `fittrack/__init__.py` | מסמן ל-Python שהתיקייה היא חבילה |
| `requirements.txt` | רשימת הספריות להתקנה |
| `.streamlit/config.toml` | צבעים בסיסיים וכיבוי סטטיסטיקה של Streamlit |
| `data/fittrack.db` | נוצר אוטומטית בהפעלה הראשונה |

## גבולות הגרסה הזו

- משתמש אחד על המחשב.
- גיל 18 עד 80, וטווחי גובה ומשקל שמוגדרים ב-`fittrack/validation.py`.
- ערכי המזון כלליים, לא מותג מסוים.
- תוכנית האימון כללית ואינה מחליפה מאמן, במיוחד כשיש פציעה או מצב רפואי.
